</p>

---

## 📌 About

AI Chatbot Web Application is a GPT-style chatbot that allows users to have 
intelligent conversations powered by Google Gemini API. Users can create new 
chats, continue previous conversations, and delete chats — all stored 
persistently in MongoDB.

---

## 🚀 Features

- 🤖 AI-powered responses using **Google Gemini API**
- 💬 Create, continue & delete **chat conversations**
- 🕓 **Persistent chat history** stored in MongoDB
- ⚡ **Real-time responses** with seamless UI updates
- 📝 **Markdown rendering** for formatted AI responses
- 🎨 Clean and responsive **React-based interface**
